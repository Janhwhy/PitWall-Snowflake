# Slim dependency set for the deployed FastAPI service (api/main.py).
#
# The full requirements.txt also covers the offline ingest pipeline
# (fastf1, faster-whisper, yt-dlp, anthropic), none of which the running
# API imports. Deploying with this file instead keeps the Render build
# smaller/faster and the runtime memory footprint lower.
#
# chromadb / sentence-transformers / torch were dropped here after the
# Snowflake migration — Cortex Search embeds server-side now, so the API
# no longer needs a local embedding model. They (and the CPU-only torch
# preinstall step) only remain in requirements.txt, for the RAG_BACKEND=
# chromadb local fallback (utils/retriever_chromadb.py) — never imported
# in production.
#
# Re-run ingest scripts locally with `pip install -r requirements.txt`.
fastapi
uvicorn[standard]
groq
python-dotenv
pandas
snowflake-connector-python[secure-local-storage]
